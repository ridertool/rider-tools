→바로길 사용법

콜 받는 폰에서 주소를 보내면 내비 폰에 바로 떠요. 내비 폰에서 버튼 한 번이면 길안내가 시작돼요.

준비 처음 한 번만

  1. 두 폰에서 바로길 주소를 크롬으로 열기받은 링크를 콜 폰과 내비 폰 둘 다에서 엽니다.
  2. 홈 화면에 추가 (추천)크롬 오른쪽 위 메뉴(⋮) → ‘홈 화면에 추가’. 다음부터 앱처럼 아이콘으로 열려요.
  3. 두 폰 연결하기한 폰에서 새 연결 코드 만들기 → 연결 링크 복사를 누르고, 그 링크를 카톡 ‘나와의 채팅’으로 보내서 다른 폰에서 엽니다. 링크 대신 화면의 10자리 코드를 직접 입력해도 돼요.
  4. 폰마다 역할 고르기화면 위쪽에서 콜 폰은 ‘콜 받는 폰’, 내비 폰은 ‘내비 폰’을 누릅니다. 한 번 고르면 기억해요.

콜 받을 때 매번

  1. 콜 받는 폰
    콜 앱에서 주소 복사주소를 길게 눌러 복사합니다.
  2. 콜 받는 폰
    바로길에 붙여넣고 보내기주소 칸에 붙여넣고 내비 폰으로 보내기. 층수·공동현관 비번 같은 건 메모 칸에 적으면 같이 가요.
  3. 내비 폰
    원하는 내비 누르기소리·진동과 함께 목적지가 뜨면 카카오맵티맵네이버 중 하나를 누르면 길안내가 시작돼요.
연결 코드와 연결 링크는 남에게 보내지 마세요. 그걸 가진 사람은 내 목적지를 볼 수 있어요. 바로길 사이트 주소는 마음껏 나눠도 괜찮아요. 사람마다 자기 코드로 따로 연결돼요.

잘 안 될 때

목적지가 안 떠요
내비 폰에서 바로길 화면이 열려 있어야 바로 받아요. 다른 앱을 쓰다가 바로길로 돌아오면 그사이 온 주소를 자동으로 불러와요. 위쪽 표시가 ‘연결됨’인지 확인하세요.
내비 버튼을 눌러도 반응이 없어요
그 내비 앱이 깔려 있는지 확인하세요. 안 되면 아래 ‘웹 지도’ 링크를 쓰거나 ‘주소 복사’ 후 내비 앱에 직접 붙여넣으세요.
화면이 자꾸 꺼져요
내비 폰에서 ‘이 화면 켜두기’를 체크하세요.
폰을 바꿨거나 다시 연결하고 싶어요
‘연결 코드’ 버튼 → ‘연결 끊기’를 누른 뒤 준비 3번부터 다시 하세요.
소리가 안 나요
바로길 화면을 한 번 터치해 두면 소리가 나요. ‘새 목적지 오면 소리·진동’이 체크돼 있는지도 확인하세요.
